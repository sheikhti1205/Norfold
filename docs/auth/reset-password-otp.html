This file is no longer an email template

The canonical Norfold password-reset email is supabase/email-templates/reset-password.html in this repository. Paste that file into Supabase under Authentication → Emails → Reset Password.

Norfold recovers passwords with a six-digit code from the email. There is no link to open, so the reset template offers none.

See docs/auth/owner-setup.md for the full owner checklist.
